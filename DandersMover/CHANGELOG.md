# DandersMover Changelog

## [1.0.0]

First release as its own addon.

- One editor, `/mover`, for every addon that supports DandersMover.
- Snap to a grid, the screen edges and other frames.
- Anchor frames to each other, even across addons, with a backup anchor for when the target isn't on screen.
- Frames anchored to another addon's frames follow them automatically.
- Mirror two frames around a centre line.
- Undo, redo, save and discard.
- For addon authors: register a frame in about ten lines. See the Developer Guide on GitHub.
